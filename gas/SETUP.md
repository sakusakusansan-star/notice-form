# Discord 連携のセットアップ

お知らせを投稿すると Discord に自動で流れ、日程の**前日**になるとアラートが飛ぶようにします。
作業は Google Apps Script（GAS）側だけです。このリポジトリの HTML はそのままで動きます。

---

## ⚠️ 最初に：Webhook URL は絶対にここに書かない

Discord の Webhook URL は「これを知っている人は誰でもそのチャンネルに投稿できる」鍵です。
このリポジトリは GitHub Pages で公開されているので、`index.html` やコードに直接書くと
URL が全世界に見えてしまいます。

そのため URL は **GAS のスクリプトプロパティ**（外から見えない保管場所）に入れます。
手順は下の 2 番です。

---

## 1. スクリプトをコピーする

1. お知らせを保存しているスプレッドシートを開く
2. メニューの **拡張機能 → Apps Script** を開く
3. 左の「ファイル」の **＋ → スクリプト** で新しいファイルを作り、名前を `NoticeDiscord` にする
4. `gas/NoticeDiscord.gs` の中身を全部コピーして貼り付ける
5. 保存（💾）

### すでに doGet / doPost がある場合

`NoticeDiscord.gs` を足すだけで OK です。あとは既存の `doPost` の中、
**保存が成功した直後**に 1 行足します。

```js
// 新規投稿の保存が終わったところで
notifyDiscord('create', {
  id: id, name: name, type: type, text: text,
  when: when, time: time, expire: expire
});

// 更新なら 'update'、削除なら 'delete'
```

`gas/Code.gs` は貼らなくて構いません。

### バックエンドをこれから作る／作り直す場合

`gas/Code.gs` も同じ手順でもう 1 ファイル追加してください。
`doGet` / `doPost` / 投稿・更新・削除・Discord 通知がひと通り入っています。

シートの 1 行目（見出し）はこの並びにしてください。空のシートなら初回投稿時に自動で作られます。

| id | name | type | text | when | time | expire | created |
|----|------|------|------|------|------|--------|---------|

> 見出しは日本語（`投稿者` `種別` `内容` `日程` `時間` `表示期限`）でも認識します。
> 列の順番が違っても大丈夫です。

---

## 2. Webhook URL を登録する

1. Apps Script の左下 **⚙️ プロジェクトの設定** を開く
2. 一番下の **スクリプト プロパティ** → **スクリプト プロパティを追加**
3. 次のように入力して保存

   - プロパティ： `DISCORD_WEBHOOK_URL`
   - 値： Discord で発行した Webhook URL（`https://discord.com/api/webhooks/...`）

これで URL はコードにも GitHub にも残りません。

> Webhook URL の作り方：Discord で投稿先チャンネルの **⚙️ → 連携サービス → ウェブフック → 新しいウェブフック** →
> 「ウェブフック URL をコピー」

---

## 3. 前日アラートのトリガーを作る

1. Apps Script のエディタ上部の関数プルダウンで **`setupTriggers`** を選ぶ
2. **実行** を押す
3. 初回は「承認が必要です」と出るので、アカウントを選んで許可する

これで **毎朝 9:00（日本時間）** に、翌日が日程になっているお知らせを Discord に流します。
同じお知らせが二重に飛ばないよう、送信済みは記録されます。

---

## 4. 動作確認

エディタの関数プルダウンから手動実行できます。

| 関数 | 内容 |
|------|------|
| `testDiscord` | テスト投稿を 1 件 Discord に送る |
| `testDailyAlert` | 明日が日程のお知らせに対して、前日アラートを今すぐ送る |

Discord に届かないときは、エディタ左の **実行数** からログを確認してください。
`スクリプトプロパティ DISCORD_WEBHOOK_URL が未設定` と出ていれば 2 番をやり直しです。

---

## 5. 再デプロイ（`Code.gs` を入れた場合のみ）

`doGet` / `doPost` を変更したときは、反映のために再デプロイが必要です。

**デプロイ → デプロイを管理 → ✏️（編集） → バージョン「新バージョン」 → デプロイ**

URL は変わらないので、`index.html` の `NOTICE_API` はそのままで大丈夫です。

---

## 設定を変えたいとき

`NoticeDiscord.gs` の先頭にまとまっています。

| 変数 | 既定値 | 内容 |
|------|--------|------|
| `ALERT_HOUR` | `9` | 前日アラートを送る時刻（0〜23）。変えたら `setupTriggers` を再実行 |
| `ALERT_MENTION` | `'@here'` | アラート時のメンション。鳴らしたくなければ `''` |
| `MENTION_IMPORTANT` | `true` | 種別「重要」の投稿でもメンションするか |
| `SHEET_NAME` | `''` | 対象シート名。空なら先頭シート |
| `TYPE_COLOR` | — | 種別ごとの Discord 埋め込みの色 |
